Install Hangarin App

Install Hangarin on your phone, tablet, or desktop for fast offline task management.

How to install on your device:
Apple iOS (iPhone / iPad / Safari):
1. Tap the Share button (square with arrow up).
2. Scroll down and select "Add to Home Screen".
Android / Mobile Browser:
1. Tap the 3 dots menu (⋮) top-right.
2. Select "Install app" or "Add to Home screen".
